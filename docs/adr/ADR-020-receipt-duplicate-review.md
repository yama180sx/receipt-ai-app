# ADR-020: レシートの重複候補を利用者が確認する

状態: Accepted

## 背景

同一レシートを異なる角度で撮影すると画像ハッシュは一致せず、AI は同じ店舗を異なる表記で返すことがある。一方、日時や金額だけで店名の異なる候補をすべて提示すると、無関係なレシートが頻繁に表示される。

## 決定

店名・日時・金額の欠落は利用者に入力を求め、現在日時などを補完しない。世帯内で金額と日時が一致し、店舗マスタの別名または限定された表記変換で店名も一致するものを候補として表示する。日付のみの場合は当日、時刻がある場合は前後１分を対象とする。DAISO とダイソーの置換は支店名を残して比較する。

利用者は候補と今回の画像を確認し、別のレシートとして保存できる。保存トランザクションは世帯単位で直列化し、未確認の候補が現れた場合は再確認を求める。元画像の完全一致による冪等処理は維持する。画像比較用の追加 AI 呼び出しは行わない。

## 影響と限界

登録されていない表記揺れ、誤った日時や金額は見逃す場合がある。表記統一は慎重に追加し、誤検知と見逃しを測定する。保存済み画像がない場合は登録情報を表示する。実端末で画像の拡大・比較を確認する。
