# ADR-006: 車用燃料を標準商品種別とし交通カテゴリ名を統一する

Status: Accepted

## 決定

標準カテゴリ `交通・通信` 配下に最下層 ProductType `燃料（車用）` を追加する。ガソリン、レギュラー、ハイオク、軽油は全世帯共通の `StandardProductClassificationRule` によりこのProductTypeへ分類する。

世帯別 `Category` の旧名称 `交通費` は `交通・通信` に統一する。同一世帯で両名称が共存する場合は既存の `交通・通信` を正とし、明細参照を移してから旧カテゴリを削除する。

## 理由

車用燃料の分類を、個別のカテゴリ推定ロジックではなく既存の標準 ProductType 分類フローで扱うため。標準カテゴリ名と世帯別カテゴリ名を一致させることで、ProductType の親標準カテゴリから世帯内の集計カテゴリを既存の名称一致処理で安全に解決できる。

## 影響

新規・更新の燃料明細は `categoryId` を世帯内の `交通・通信` に、`standardCategoryId` を標準 `交通・通信` に、`productTypeId` を `燃料（車用）` に保存する。洗車、カー用品、併設店舗商品、EV充電、灯油は車用燃料用の標準ルールに含めない。DBスキーマ列、公開API、BullMQ、外部AIの変更は不要であり、既存データのカテゴリ名統一だけをmigrationで行う。
