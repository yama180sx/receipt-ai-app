# ADR-007: Geminiモデルを用途別の固定環境設定にする

Status: Accepted

## 決定

レシート画像OCRと商品分類で、`GEMINI_RECEIPT_MODEL` と
`GEMINI_PRODUCT_CLASSIFICATION_MODEL` を別々に設定する。既定値は
`gemini-3.5-flash-lite` とし、`*-latest` のように参照先が変化する別名は使用しない。

## 理由

モデル提供終了時にソースコードの変更を伴わず、検証済みの固定モデルIDへ切り替えられるようにする。
OCRと分類は品質・費用・入力形式が異なるため、移行判断も分離する。値はプロセス起動時に一度だけ
確定するため、解析リクエストごとの性能劣化はない。

## 影響

切替には環境変数の変更とbackend再デプロイが必要である。切替前に実レシートと分類契約の手動検証を
行い、問題時は直前の固定IDへ戻す。有効なロールバック先がない場合、OCRは手入力へ誘導し、
自動フォールバックは行わない。
