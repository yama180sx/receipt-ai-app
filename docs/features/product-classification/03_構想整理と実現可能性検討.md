# 商品単位AI自動分類 — 構想整理と実現可能性検討

## 実現方針

既存のGemini OCR、PostgreSQL、Prisma、世帯分離を活かし、分類を段階導入する。完全一致を先行し、`pg_trgm`類似検索とAIは後続に分けるため、Phase 1で外部AIに依存せず価値を検証できる。

## 主なリスク

- OCRの表記揺れは完全一致だけでは解決できない。
- 類似検索の自動確定は誤分類を生むため候補提示に限定する。
- AIの自己申告信頼度だけでは確定できないため、候補制約・検証・修正率評価が必要である。
- 旧ProductMaster廃止は破壊的なデータ初期化を伴うため、開発環境で先行検証する。
